Méthode. Requêtes search/repositories triées par étoiles, filtrées sur la présence de « mcp » dans le nom du dépôt ou ses topics ; 196 dépôts uniques ramenés, 31 retenus à la lecture des descriptions. Les comptes d'outils sont ceux que le code déclare (décorateurs, registres) quand le motif est reconnaissable — sinon la cellule reste vide plutôt que d'inventer un chiffre.

Limite. L'API de recherche classe par popularité, pas par qualité : un dépôt à 12 000 étoiles peut n'avoir aucun rapport avec l'administration serveur. C'est précisément ce que le cap éditorial exploite.
