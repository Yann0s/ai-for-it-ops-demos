## Règles faceless

1. Aucun visage — identité portée par la palette + le badge « AIOPS » fixe + la structure de miniature identique
2. Miniature 1280×720 : fond sombre + code flouté, visuel central fort, titre 3–5 mots, badge « AIOPS » en haut à droite, lisible à 128×72 px
3. Intro 3 s fixe : logo animé + commande tapée en mono verte + jingle court
4. Overlays sobres : chapitres en mono verte, transitions sèches (cut)
5. Outro fixe : écran sombre, logo, 2 vidéos suggérées, CTA « S'abonner » en vert
